# Traycer Scoop bucket

Install Traycer Desktop on Windows with [Scoop](https://scoop.sh):

```powershell
scoop bucket add traycer https://github.com/traycerai/scoop-traycer
scoop install traycer-desktop
```

Update with `scoop update traycer-desktop`. Uninstall with `scoop uninstall traycer-desktop`.

The manifest in `bucket/` is updated by Traycer's release workflow for every stable desktop release. Report problems at [traycerai/traycer](https://github.com/traycerai/traycer/issues).
